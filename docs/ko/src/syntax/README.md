# 문법

Rusk는 네 군데에서 Rust와 다르다:

- [블록](blocks.md)은 `:`로 열고 들여쓰기로 닫는다. 문장은 줄 끝에서 끝난다.
- [표현식](expressions.md)에 `if c then a else b`가 있고, `if`, `match`, 클로저 블록을 값 자리에
  쓸 수 있다.
- [경로와 제네릭](paths.md)은 Rust의 `::`와 `<T>` 대신 `.`와 `[T]`를 쓴다.
- [포맷 문자열](macros.md)에 `{user.name()}` 같은 인라인 표현식을 쓸 수 있다.

나머지는 Rust와 같다. Rust의 `{ ... }` 블록, `::` 경로, `::<T>` 터보피시는 언제나 쓸 수 있고
쓴 그대로 유지된다.
