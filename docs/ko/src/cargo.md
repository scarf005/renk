# Cargo 프로젝트

Cargo가 `.rs` 파일을 기대하는 자리에 `.rsk` 파일을 둔다. 다음 명령은 `src`, `examples`, `tests`,
`benches` 아래의 모든 `.rsk` 파일과 `build.rsk`를 각각 옆의 `.rs` 파일로 트랜스파일한 뒤 같은
Cargo 명령을 실행한다:

```sh
rusk build
rusk check
rusk run
rusk test
rusk clippy
rusk doc
rusk bench
rusk cargo ARGS...  # any other cargo command, as cargo ARGS...
```

생성된 파일은 `// @generated by rusk; do not edit.`로 시작하며, 내용이 바뀔 때만 다시 쓴다. 이
헤더가 없는 `.rs` 파일은 덮어쓰지 않고 오류로 멈춘다.

`src/main.rsk`:

```rsk
fn main():
    println!("{double(21)}")

fn double(n: i32) -> i32 = n * 2

#[cfg(test)]
mod tests:
    #[test]
    fn doubles():
        assert_eq!(super.double(2), 4)
```

`rusk run`은 `42`를 출력하고, `rusk test`는 `doubles`를 실행한다. 본문 없는 `mod name`은 Rust의
`mod name;`처럼 모듈 파일을 선언한다.
