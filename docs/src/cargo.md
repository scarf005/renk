# Cargo projects

Put `.rsk` files where Cargo expects `.rs` files. These commands transpile every `.rsk` file
under `src`, `examples`, `tests`, and `benches`, plus `build.rsk`, to a `.rs` file beside it,
then run the same Cargo command:

```sh
rusk build
rusk check
rusk run
rusk test
rusk clippy
rusk doc
rusk bench
rusk cargo ARGS...  # any other cargo command, as cargo ARGS...
```

A generated file starts with `// @generated by rusk; do not edit.` and is rewritten only when
its content changes. rusk stops with an error instead of overwriting a `.rs` file without that
header.

`src/main.rsk`:

```rsk
fn main():
    println!("{double(21)}")

fn double(n: i32) -> i32 = n * 2

#[cfg(test)]
mod tests:
    #[test]
    fn doubles():
        assert_eq!(super.double(2), 4)
```

`rusk run` prints `42`, and `rusk test` runs `doubles`. `mod name` without a body declares a
module file, as `mod name;` does in Rust.
